# FEP-6757: Content License Metadata in ActivityPub

## Summary

An explicit copyright license on ActivityPub content objects makes it easier to re-use and re-distribute content.

## Introduction

Copyright licensing is an important part of metadata for Web resources. It lets publishers express the rights they have granted beyond the defaults for re-use of their work. It lets consumers understand if and how they can re-use content beyond the basic grants of copyright or fair use/fair dealing.

[Creative Commons](https://creativecommons.org/) defined a suite of licenses in 2002 which have been revised, localised, globalised and expanded over the last few decades. The [licenses](https://creativecommons.org/cc-licenses/) define a few grant types, such as re-use with attribution, for non-commercial use, in verbatim form, and/or with an identical license. The [CC0 Public Domain Dedication](https://creativecommons.org/public-domain/) lets publishers express their intent to put their work in the public domain, to the extent possible in applicable law.

## Motivation

[FEP-C118] argues creatively for content licensing support on the Fediverse.

The solutions provided in this document aim to satisfy at least the following user stories:

- *As a content publisher, I want to express what I want and don't want done with my content, so that it doesn't get misused*.
- *As a utility developer, I want to know what I'm allowed to do with a piece of content, so I don't overstep the author's intent with the work.*
- *As a client app developer, I want to know what an actor's preferred default content license is, so I can set it by default on newly-created work.*
- *As an ActivityPub software user, I want to use tools that re-publish and re-order and re-mix content, so I can enjoy it in new and interesting ways.*

## Context document

The context document for this vocabulary is available at <https://w3id.org/fep/6757>. It defines two terms, `license` and `preferredLicense`:

```json
{
  "@context": {
    "license": "http://purl.org/dc/terms/license",
    "preferredLicense": "https://w3id.org/fep/6757#preferredLicense"
  }
}
```

### `license` property

- **URI**: <http://purl.org/dc/terms/license>
- **Notes**: The license for the object. It is the [Dublin Core Metadata Terms] `license` property.
- **Domain**: Any resource.
- **Range**: <http://purl.org/dc/terms/LicenseDocument>
- **Functional**: false. Multiple values indicate separate licenses that the consumer may choose from at their option.

### `preferredLicense` property

- **URI**: <https://w3id.org/fep/6757#preferredLicense>
- **Notes**: The preferred license for new objects created by the actor.
- **Domain**: [Object](https://www.w3.org/TR/activitystreams-vocabulary/#dfn-object) (an [ActivityPub actor](https://www.w3.org/TR/activitypub/#actors))
- **Range**: <http://purl.org/dc/terms/LicenseDocument>
- **Functional**: true.

## License identifiers

Publishers MUST use URIs to identify licenses. Publishers MUST NOT use license names like "Creative Commons Attribution 4.0 International" or identifiers like [SPDX short identifiers](https://spdx.github.io/spdx-spec/v2.3/SPDX-license-list/#a1-licenses-with-short-identifiers).

Publishers SHOULD use the following URIs to identify their respective license terms.

- The Creative Commons [Licenses List]. The canonical URI SHOULD be used. For example, use <https://creativecommons.org/licenses/by-nc-nd/4.0/>, not <https://creativecommons.org/licenses/by-nc-nd/4.0/deed.en> or <https://creativecommons.org/licenses/by-nc-nd/4.0/legal-code>.
- The CC0 URI, <https://creativecommons.org/publicdomain/zero/1.0/>.
- The Creative Commons Public Domain Mark, <https://creativecommons.org/publicdomain/mark/1.0/>.
- [Rights Statements], including <https://rightsstatements.org/vocab/InC/1.0/> for "In copyright". Absent any other license information, this is a good indication that no other rights have been granted, that is, "all rights reserved".

Publishers MAY use other URIs for licenses not included in this list.

Public domain, CC0, and "all rights reserved" are not strictly speaking "copyright licenses", but publishers SHOULD use their URIs as license identifiers for the `license`, `preferredLicense`, and other license-related properties.

## Content objects

[ActivityPub objects](https://www.w3.org/TR/activitypub/#obj) of type [Note](https://www.w3.org/TR/activitystreams-vocabulary/#dfn-note), [Article](https://www.w3.org/TR/activitystreams-vocabulary/#dfn-article), [Image](https://www.w3.org/TR/activitystreams-vocabulary/#dfn-image), [Video](https://www.w3.org/TR/activitystreams-vocabulary/#dfn-video), and [Audio](https://www.w3.org/TR/activitystreams-vocabulary/#dfn-audio) are the type of expressive content that is often re-used and re-distributed.

Publishers SHOULD include a `license` property on content-type objects.

Publishers MAY add license metadata to other ActivityPub objects, including actors, collections, and activities.

Publishers MAY include the <https://schema.org/#license> property as an alternative or additional property for content objects.

Publishers MAY include the <https://creativecommons.org/ns#license> property as an alternative or additional property for content objects.

Publishers MUST NOT define `license`, `schema:license` and `cc:license` properties with different values for the same object.

In the absence of a `license` or synonymous property for a content object, consumers SHOULD treat the object as if its `license` were <https://rightsstatements.org/vocab/InC/1.0/>, that is, "all rights reserved".

### Example

The following `Note` object is marked with the Creative Commons Attribution license using the `license` property and the `schema:license` property. Its attached `Link` object is marked with the public domain mark.

```json
{
  "@context": [
    "https://www.w3.org/ns/activitystreams",
    "https://w3id.org/fep/6757",
    { "schema": "https://schema.org/#" }
  ],
  "id": "https://social.example/note/857",
  "type": "Note",
  "content": "Hello, world!",
  "license": "https://creativecommons.org/licenses/by/4.0/",
  "schema:license": "https://creativecommons.org/licenses/by/4.0/",
  "attachments": {
    "type": "Link",
    "href": "https://media.social.example/uploads/file339.jpg",
    "mediaType": "image/jpeg",
    "license": "https://creativecommons.org/publicdomain/mark/1.0/"
  }
}
```

## Actors

Publishers MAY include a `preferredLicense` property for ActivityPub actors, to indicate the preferred license for new ActivityPub objects that the actor creates.

Client applications SHOULD use the value of the `preferredLicense` property as the default `license` property when creating new ActivityPub objects, such as with the ActivityPub API. Client applications SHOULD provide options for the user to choose a different `license` property value.

Consumers SHOULD NOT treat the `preferredLicense` property of an actor as a fallback license for content objects that do not have their own `license` property.

### Examples

The following actor has a `license` property for their profile data, and a separate license for their avatar. They have a `preferredLicense` property for any new content created by this actor.

```json
{
  "@context": [
    "https://www.w3.org/ns/activitystreams",
    "https://w3id.org/fep/6757"
  ],
  "id": "https://social.example/user/1753",
  "type": "Person",
  "name": "Example User",
  "inbox": "https://social.example/collection/9257",
  "outbox": "https://social.example/collection/10772",
  "summary": "An example user who is very illustrative of important features",
  "license": "https://creativecommons.org/licenses/by-nc-nd/4.0",
  "icon": {
    "type": "Image",
    "license": "https://creativecommons.org/licenses/by-nc/4.0",
    "url": {
      "type": "Link",
      "mediaType": "image/jpeg",
      "href": "https://media.social.example/upload/7272.jpg",
    }
  },
  "preferredLicense": "https://creativecommons.org/licenses/by-nc/4.0"
}
```

A client app using the ActivityPub API would use the value of the `preferredLicense` property to provide the `license` property of the `object` property of a `Create` activity.

```json
{
  "@context": [
    "https://www.w3.org/ns/activitystreams",
    "https://w3id.org/fep/6757"
  ],
  "type": "Create",
  "object": {
    "type": "Note",
    "content": "Hello, world!",
    "license": "https://creativecommons.org/licenses/by-nc/4.0"
  }
}
```
